# 办公运动引导 需求文档

**版本**: v1.2.0
**创建日期**: 2026-02-19
**状态**: 开发中

## 需求背景

基于 [办公健康功能扩展技术调研](../research/office-health-research.md) 的发现：
- 办公室工作者面临久坐、颈椎病、腰椎间盘突出、腕管综合征等健康问题
- WHO 建议每 30 分钟站立一次，避免连续久坐超过 1 小时
- 长休息时段是引导用户进行办公室拉伸的最佳时机
- 将产品理念从"护眼"扩展到"办公健康守护"，覆盖更大用户群

## 需求目标

在青眸现有的护眼休息体系上，集成办公运动引导功能。核心原则：**与护眼休息协同，一次休息多维关怀**。

| ID | 功能 | 说明 |

| E5 | 运动统计 | 仪表盘新增运动统计卡片（今日站立次数、拉伸次数） |

## 数据模型

### 新增表: exercise_records

```sql
CREATE TABLE exercise_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,           -- ISO 8601
  exercise_type TEXT NOT NULL,        -- 'stand' / 'stretch'
  exercise_name TEXT,                -- 拉伸动作名称（仅 stretch 类型）
  duration INTEGER DEFAULT 0,        -- 运动时长（秒）
  source TEXT DEFAULT 'manual',      -- manual / reminder / break
  created_date TEXT NOT NULL          -- YYYY-MM-DD
);

CREATE INDEX idx_exercise_timestamp ON exercise_records(timestamp);
CREATE INDEX idx_exercise_date ON exercise_records(created_date);
```

### 新增设置字段

```typescript
interface ExerciseSettings {
  sedentaryReminder: {
    enabled: boolean           // 默认 true
    threshold: number          // 分钟，默认 30
  }
  standReminder: {
    enabled: boolean           // 默认 true
    interval: number           // 分钟，默认 60
  }
  stretchGuide: {
    enabled: boolean           // 默认 true
    showInLongBreak: boolean  // 默认 true
  }
}
```

## 拉伸动作库

### 推荐动作（8-10 个）

1. **颈部拉伸** - 左右转头、前后点头
2. **肩部拉伸** - 肩部环绕、手臂交叉拉伸
3. **腰部拉伸** - 侧弯、扭转
4. **手腕拉伸** - 手腕前后弯曲、手指拉伸
5. **背部拉伸** - 猫式伸展、背部扭转
6. **腿部拉伸** - 站立抬腿、小腿拉伸
7. **眼部放松** - 眼球转动、远近聚焦（已有）
8. **深呼吸** - 腹式呼吸（已有）

每个动作包含：
- 名称
- 步骤说明（3-5 步）
- 建议时长
- 目标部位
- 注意事项（可选）

## 技术实现要点

### 1. 久坐检测器

- 复用 `IdleDetector` 逻辑，反向推导：连续非空闲 = 连续使用
- 记录最后一次空闲时间，计算连续使用时长
- 达到阈值时触发通知（系统通知 + 可选托盘提示）

### 2. 站立提醒计时器

- 独立于护眼计时器，单独管理
- 达到间隔时触发通知
- 用户点击"已站立"后记录并重置计时

### 3. 拉伸引导模式

- 在 `RestPage` 中新增 `stretch` 模式
- Long Break 时根据设置选择显示拉伸引导
- 展示当前动作、步骤、进度
- 支持"下一个动作"切换（循环展示）
