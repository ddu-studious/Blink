# 青眸 (QingMou) 护眼桌面应用 - 需求文档

**版本**: v1.0.0  
**创建日期**: 2026-02-13  
**状态**: 规划中

---

## 1. 需求背景

### 1.1 问题描述

长时间面对电脑屏幕工作导致的视觉疲劳综合症（Computer Vision Syndrome, CVS）是现代办公人群普遍面临的健康问题。主要症状包括：

- 眼睛干涩、酸胀、疲劳
- 视力模糊、对焦困难
- 头痛、颈肩疼痛
- 注意力下降

### 1.2 科学依据

**20-20-20 法则** 是美国眼科学会 (AAO) 推荐的护眼方法：

> 每使用电脑 **20 分钟**，看向 **20 英尺**（约 6 米）外的物体，持续 **20 秒**。

此外，每工作 **1-2 小时**应进行一次 **5-10 分钟**的较长休息，活动身体、放松肩颈。

### 1.3 目标用户

- **主要用户**: 长时间使用电脑的程序员、设计师、文字工作者
- **次要用户**: 学生、远程办公人群、游戏玩家
- **特征**: 
  - 日均使用电脑 6-12 小时
  - 使用 macOS / Windows / Linux 系统
  - 可能使用多显示器
  - 经常进入沉浸式工作状态，忘记休息

### 1.4 产品目标

构建一个**轻量、美观、智能**的跨平台护眼桌面应用，帮助用户：

1. 科学定时提醒用眼休息
2. 培养健康的用眼习惯
3. 追踪和量化护眼行为
4. 在不打扰关键工作的前提下提供有效提醒

## 2. 产品概述

### 2.1 产品定位

| 维度 | 说明 |
|------|------|
| **产品名称** | 青眸 / QingMou |
| **产品类型** | 跨平台桌面应用 (macOS / Windows / Linux) |
| **核心价值** | 科学、智能、美观的护眼提醒 |
| **差异化** | 双级提醒 + 多屏覆盖 + 统计可视化 + 智能场景感知 |

### 2.2 产品理念

- **科学**: 基于 20-20-20 法则，结合长休息机制
- **智能**: 感知用户状态（空闲/锁屏/演示模式），不做无意义打扰
- **美观**: 现代化 UI 设计，休息页面赏心悦目
- **克制**: 尊重用户自主权，提供跳过选项但鼓励坚持

## 3. 功能需求

### 3.1 P0 - 核心功能 (MVP)

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| **F01** | **系统托盘常驻** | 应用启动后缩小到系统托盘(状态栏)，不显示主窗口；托盘图标可显示倒计时进度 | P0 |
| **F02** | **托盘右键菜单** | 包含：开始/暂停护眼、跳到下次休息、设置、关于、退出 | P0 |
| **F03** | **Mini Break 短休息** | 默认每 20 分钟提醒一次，休息 20 秒（20-20-20 法则）；弹出全屏休息页面显示倒计时 | P0 |
| **F04** | **Long Break 长休息** | 默认每 60 分钟提醒一次，休息 5 分钟；弹出全屏休息页面显示倒计时 + 活动建议 | P0 |
| **F05** | **休息页面 UI** | 全屏半透明覆盖，居中显示倒计时数字；背景模糊效果；可显示护眼小知识 | P0 |
| **F06** | **跳过休息** | 休息页面提供"跳过"按钮(可设置延迟显示，如 5 秒后才出现) | P0 |
| **F07** | **系统通知** | 休息开始前 30 秒发送系统通知预告；如用户不希望全屏覆盖可仅用通知 | P0 |
| **F08** | **休眠/唤醒感知** | 电脑休眠时自动暂停计时，唤醒后重新开始；锁屏时同理 | P0 |
| **F09** | **用户设置持久化** | 保存用户设置到本地(时间间隔、休息时长、主题、声音等) | P0 |
| **F10** | **开机自启动** | 支持设置开机时自动启动应用 | P0 |

### 3.2 P1 - 重要功能

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| **F11** | **空闲检测** | 用户空闲超过指定时长(如 5 分钟)自动暂停计时；活动恢复后重新开始 | P1 |
| **F12** | **多屏覆盖** | 使用多显示器时，休息遮罩覆盖所有屏幕；支持动态插拔显示器 | P1 |
| **F13** | **免打扰模式感知** | 检测系统免打扰/勿扰模式(macOS Focus / Windows Focus Assist)，自动暂停提醒 | P1 |
| **F14** | **声音提示** | 休息开始/结束时播放提示音；可自定义或关闭 | P1 |
| **F15** | **主题切换** | 支持亮色/暗色/跟随系统三种主题模式 | P1 |
| **F16** | **设置界面** | 独立设置窗口，可配置所有参数：时间间隔/时长/声音/主题/通知方式等 | P1 |
| **F17** | **使用统计 (基础)** | 记录每日休息次数、跳过次数、总休息时长；展示简单统计 | P1 |
| **F18** | **全局快捷键** | 自定义全局快捷键：暂停/恢复、立即休息、跳过 | P1 |
| **F19** | **休息页面内容** | Mini Break 显示护眼小知识/远眺提示；Long Break 显示伸展运动建议 | P1 |

| **F34** | **健康报告** | 生成周报/月报，总结用眼健康状况 | P3 |

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 内存占用 (空闲) | < 80MB | 仅系统托盘运行时 |
| 内存占用 (休息) | < 150MB | 显示全屏休息页面时 |
| CPU 占用 (空闲) | < 1% | 正常计时状态 |
| 启动速度 | < 3 秒 | 从启动到托盘图标可见 |
| 休息窗口弹出 | < 500ms | 从计时到达到窗口显示 |
| 安装包大小 | < 100MB | 压缩后安装包 |

### 4.2 兼容性要求

| 平台 | 最低版本 | 说明 |
|------|---------|------|
| macOS | 10.15 (Catalina) | 支持 Intel + Apple Silicon |
| Windows | Windows 10 | 64-bit |
| Linux | Ubuntu 20.04+ | AppImage / deb / rpm |

### 4.3 安全要求

| 要求 | 说明 |
|------|------|
| 上下文隔离 | 渲染进程启用 `contextIsolation: true` |
| 沙箱模式 | 渲染进程启用 `sandbox: true` |
| IPC 安全 | 通过 `contextBridge` 暴露最小 API |
| 数据安全 | 用户数据仅存本地，不上传任何服务器 |
| 代码签名 | macOS / Windows 安装包代码签名 |

### 4.4 用户体验要求

| 要求 | 说明 |
|------|------|
| 首次启动引导 | 欢迎页面引导用户了解功能和设置 |
| 渐进式提醒 | 先通知再全屏，给用户缓冲时间 |
| 非侵入性 | 空闲/锁屏/免打扰时不打扰用户 |
| 优雅过渡 | 休息页面淡入淡出，不突兀 |
| 低电量友好 | 电池模式下降低提醒频率（可配置） |

## 5. 用户场景 (User Stories)

### 5.1 基础使用场景

#### US-01: 首次安装和启动

```
作为 新用户
我想要 安装后看到欢迎引导
以便 了解应用的核心功能和初始设置

验收标准:
- [ ] 首次启动显示欢迎窗口
- [ ] 引导用户了解 20-20-20 法则
- [ ] 允许用户设置基本偏好（提醒间隔、是否开机自启）
- [ ] 引导完成后缩小到系统托盘
```

#### US-02: 日常护眼提醒

```
作为 长时间工作的用户
我想要 定期收到休息提醒
以便 保护我的视力

验收标准:
- [ ] 每 20 分钟弹出 Mini Break (20 秒倒计时)
- [ ] 每 60 分钟弹出 Long Break (5 分钟倒计时)
- [ ] 休息页面美观、不刺眼
- [ ] 倒计时结束后自动关闭
- [ ] 可通过跳过按钮提前结束
```

#### US-03: 系统托盘操作

```
作为 用户
我想要 通过系统托盘快速操作
以便 不需要打开主界面就能控制应用

验收标准:
- [ ] 托盘图标始终可见
- [ ] 鼠标悬停显示倒计时信息
- [ ] 右键菜单包含常用操作
- [ ] 左键单击显示快速信息弹窗（可选）
```

### 5.2 智能场景

#### US-04: 离开电脑时自动暂停

```
作为 经常离开工位的用户
我想要 应用能自动识别我离开了
以便 不在我不在时白白消耗计时

验收标准:
- [ ] 空闲超过 5 分钟自动暂停计时
- [ ] 回来后自动恢复计时
- [ ] 如果空闲时间足够长(如超过休息时长)，视为已休息
- [ ] 锁屏时自动暂停
```

#### US-05: 演示/会议时不打扰

```
作为 需要做演示/参加视频会议的用户
我想要 应用不在关键时刻弹出提醒
以便 不影响我的工作

验收标准:
- [ ] 检测系统免打扰模式开启时暂停提醒
- [ ] 检测全屏应用时暂停提醒（可配置）
- [ ] 暂停原因消失后自动恢复
- [ ] 托盘图标显示"已暂停"状态
```

#### US-06: 电脑休眠后恢复

```
作为 合上笔记本出去吃饭的用户
我想要 回来后计时器正确恢复
以便 不会出现时间混乱

验收标准:
- [ ] 休眠时暂停计时器
- [ ] 唤醒后重新开始计时
- [ ] 如果休眠时间超过一个休息周期，重置计时器
- [ ] 状态栏显示正确的倒计时
```

### 5.3 多屏场景

#### US-07: 多显示器全覆盖

```
作为 使用多个显示器的用户
我想要 休息时所有屏幕都被覆盖
以便 真正让我的眼睛远离屏幕

验收标准:
- [ ] 休息窗口覆盖所有已连接的显示器
- [ ] 每个显示器上的覆盖正确对齐
- [ ] 主显示器上显示倒计时和跳过按钮
- [ ] 外接显示器热插拔时正确响应
```

### 5.4 统计场景

#### US-08: 查看护眼统计

```
作为 关注健康的用户
我想要 查看我的护眼统计数据
以便 了解自己的用眼习惯并持续改进

验收标准:
- [ ] 查看今日休息次数 / 跳过次数 / 总休息时长
- [ ] 查看本周/本月的趋势图表
- [ ] 查看连续坚持天数
- [ ] 查看休息达成率
```

### 5.5 边界场景

#### US-09: 强制休息 (防作弊)

```
作为 自控力不强的用户
我想要 启用强制休息模式
以便 确保我真的在休息

验收标准:
- [ ] 可在设置中启用"严格模式"
- [ ] 严格模式下无跳过按钮
- [ ] 检测到鼠标/键盘活动时重置休息倒计时
- [ ] 可设置每次休息最多重置 N 次
```

#### US-10: 番茄钟联动

```
作为 使用番茄工作法的用户
我想要 护眼提醒与番茄钟协调
以便 不互相冲突

验收标准:
- [ ] 可启用番茄钟模式 (25 分钟工作 + 5 分钟休息)
- [ ] 番茄钟休息与护眼长休息合并
- [ ] 番茄钟工作期间仍触发 Mini Break
- [ ] 统计区分番茄钟休息和护眼休息
```

  id INTEGER PRIMARY KEY AUTOINCREMENT,

  ended_at TEXT,                   -- ISO 8601
  planned_duration INTEGER NOT NULL, -- 秒
  actual_duration INTEGER,         -- 秒
  status TEXT NOT NULL,            -- 'completed' | 'skipped' | 'interrupted'

);

CREATE TABLE daily_stats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT UNIQUE NOT NULL,       -- 'YYYY-MM-DD'
  mini_breaks_completed INTEGER DEFAULT 0,
  mini_breaks_skipped INTEGER DEFAULT 0,
  long_breaks_completed INTEGER DEFAULT 0,
  long_breaks_skipped INTEGER DEFAULT 0,
  total_rest_seconds INTEGER DEFAULT 0,
  total_work_seconds INTEGER DEFAULT 0,
  first_activity_at TEXT,          -- 当天首次活动时间

);

## 10. 风险与对策

| 风险 | 影响 | 概率 | 对策 |
|------|------|------|------|
| Electron 内存占用过高 | 用户体验下降 | 中 | 按需创建窗口，空闲时销毁 |
| 原生模块编译失败 | 特定平台无法使用 | 低 | 使用纯 JS 备选方案 |
| macOS 权限问题 | 空闲检测/辅助功能受限 | 中 | 引导用户授权 + 降级方案 |
| 多屏覆盖在某些系统上异常 | 遮罩不完整 | 中 | 监听 display 事件动态调整 |
| 打包后行为与开发不一致 | 功能异常 | 中 | 持续在打包版本上测试 |
