# 正念与专注 需求文档

**版本**: v1.3.0
**创建日期**: 2026-02-19
**状态**: 开发中

## 需求背景

基于 [办公健康功能扩展技术调研](../research/office-health-research.md) 的 v1.3 路线规划：
- 长时间高压办公导致注意力疲劳和焦虑，正念练习被证实可在 3 分钟内显著降低皮质醇水平
- 休息时段是引导用户进行正念练习的黄金时机，无需额外打断工作流
- 健康知识卡片能潜移默化地提升用户健康意识，增加休息时段的价值感
- 下班提醒帮助用户建立清晰的工作边界，减少不自觉加班

## 需求目标

在青眸现有的护眼+喝水+运动体系上，集成正念引导和健康知识功能。核心原则：**复用已有休息时段，让每次休息更有价值**。

| ID | 功能 | 说明 |

| M2 | 健康知识卡片 | 休息时在底部展示随机健康小贴士（护眼/办公/饮水/运动/姿势） |

| M4 | 正念记录 | 完成的正念练习记录到数据库 |

## 数据模型

### 复用 exercise_records 表

正念练习记录复用 `exercise_records` 表，新增 `exercise_type = 'mindful'`：

```sql
-- 已有表结构足够覆盖
-- exercise_type 新增值: 'mindful'
-- exercise_name: 'breath_counting', 'body_scan', 'gratitude' 等
-- duration: 练习实际时长（秒）
-- source: 'break' (来自休息页)
```

### 新增设置字段

```typescript
interface MindfulnessSettings {
  mindfulGuide: {
    enabled: boolean           // 默认 true
    showInLongBreak: boolean  // 默认 true
  }
  healthTips: {
    enabled: boolean           // 默认 true
    categories: string[]      // 默认 ['eye', 'posture', 'water', 'exercise', 'mindful']
  }
  workEndReminder: {
    enabled: boolean           // 默认 true
    time: string              // 默认 "18:00"
    postponeMinutes: number   // 延后分钟数，默认 30
  }
}
```

### 新增 IPC 通道

```typescript
const MINDFULNESS_CHANNELS = {
  // 正念记录 (复用 exercise 通道，type='mindful')
  HEALTH_TIPS_GET: 'healthTips:get',       // 获取随机健康卡片
  WORK_END_CHECK: 'workEnd:check',         // 检查下班时间
  WORK_END_POSTPONE: 'workEnd:postpone',   // 延后下班提醒
}
```

## 正念练习库

### 推荐练习（6-8 个）

1. **呼吸计数** - 从 1 数到 7 的深呼吸循环（约 2 分钟）
2. **4-7-8 呼吸法** - 吸 4 秒、屏 7 秒、呼 8 秒，3-4 个循环
3. **身体扫描** - 从头顶到脚趾逐步感知放松（约 3 分钟）
4. **感恩冥想** - 回想三件值得感恩的小事（约 2 分钟）
5. **五感觉察** - 依次注意五种感官体验（约 2 分钟）
6. **放松肩颈** - 配合呼吸的肩颈紧张-放松（约 2 分钟）

每个练习包含：
- 名称
- 简介
- 引导步骤（文字提示序列，每步有停留时长）
- 总时长
- 适合场景

## 健康知识卡片库

### 分类

| 分类 | 示例内容 |
|------|---------|
| eye | 20-20-20 法则、屏幕亮度调节、蓝光防护 |
| posture | 正确坐姿、显示器高度、键鼠位置 |
| water | 每日饮水量、饮水时机、温度建议 |
| exercise | 久坐危害、站立办公好处、微运动 |
| mindful | 正念入门、注意力恢复、减压技巧 |

每张卡片包含：
- 分类标签
- 标题
- 内容（2-3 句话）
- 来源（可选）

## 技术实现要点

### 1. 正念引导模式

- 在 `RestPage` 中新增 `mindful` 模式
- Long Break 时根据设置选择显示正念引导
- 引导步骤按序展示，每步有设定的停留时间
- 呼吸动画使用 CSS animation（吸气-屏息-呼气节奏圆圈）
- 完成后自动记录到 exercise_records

### 2. 健康知识卡片

- 纯前端实现，卡片数据打包在渲染进程
- 在所有休息模式的底部区域展示
- 每次休息随机选取一张未展示过的卡片（按分类偏好过滤）
- 简洁的卡片 UI，不干扰主休息内容

### 3. 下班提醒

- 主进程新增 `WorkEndReminder` 模块
- 基于 `setInterval` 每分钟检查当前时间是否达到下班时间
- 触发系统通知（非全屏覆盖，不打断工作）
- 支持"延后 N 分钟"，延后后重新计时
- 每天只提醒一次（除非用户延后）
