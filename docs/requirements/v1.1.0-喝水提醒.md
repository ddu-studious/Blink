# 喝水提醒 需求文档

**版本**: v1.1.0
**创建日期**: 2026-02-18
**状态**: 规划中

## 需求背景

基于 [喝水提醒调研报告](../research/water-reminder-research.md) 的发现：
- 办公室工作者普遍存在饮水不足问题
- 过度通知会在 5 天后导致 68% 的响应率下降
- 最有效的方案是"锚定已有行为习惯"——与休息提醒绑定

## 需求目标

在青眸现有的休息提醒体系上，低成本地集成喝水提醒功能。核心原则：**与护眼休息协同，零额外打扰**。

## 功能需求

### P0 - 核心功能

| ID | 功能 | 说明 |
|----|------|------|
| W1 | 喝水功能开关 | 设置页新增"喝水提醒"区块，默认开启 |
| W2 | 每日目标设定 | 默认 2000ml (8杯)，滑块调节 1000-4000ml |
| W3 | 快速记录 | 托盘菜单: "记录喝水" → 子菜单 250ml / 500ml / 自定义 |
| W4 | 休息页面提示 | Mini/Long Break 时显示温和的喝水进度提示 |
| W5 | 托盘进度 | 托盘 tooltip 显示 "💧 3/8 杯 | 下次休息: 12:30" |
| W6 | 每日统计 | 仪表盘新增当日喝水量卡片 |

### P1 - 重要功能

| ID | 功能 | 说明 |
|----|------|------|
| W7 | 独立提醒 | 可选: 每 60-180 分钟独立通知 (默认关闭) |
| W8 | 连续打卡 | 连续达标天数 (显示在仪表盘) |
| W9 | 历史趋势 | 近 7 天 / 30 天水量折线图 |
| W10 | 水波纹动画 | 休息页面的水量动画效果 |

### P2 - 进阶功能 (可后续迭代)

| ID | 功能 | 说明 |
|----|------|------|
| W11 | 智能推荐 | 根据体重推荐每日摄入量 |
| W12 | 成就徽章 | "连续7天"、"第100杯" 等 |
| W13 | 水滴音效 | 记录时播放清脆水滴声 |

## 数据模型

### 新增表: water_records

```sql
CREATE TABLE water_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,      -- ISO 8601
  amount INTEGER NOT NULL,      -- ml
  source TEXT DEFAULT 'manual'  -- manual / quick / auto
);

CREATE INDEX idx_water_timestamp ON water_records(timestamp);
```

### 新增设置字段

```typescript
interface WaterSettings {
  enabled: boolean           // 默认 true
  dailyGoal: number          // ml, 默认 2000
  quickAmounts: number[]     // 默认 [250, 500, 750]
  showInBreak: boolean       // 休息时显示, 默认 true
  independentReminder: boolean // 独立提醒, 默认 false
  reminderInterval: number   // 独立提醒间隔分钟, 默认 90
}
```

### 新增 IPC 通道

```typescript
const WATER_CHANNELS = {
  WATER_RECORD: 'water:record',           // 记录喝水
  WATER_GET_TODAY: 'water:getToday',       // 获取今日统计
  WATER_GET_RANGE: 'water:getRange',       // 获取日期范围统计
  WATER_GET_STREAK: 'water:getStreak',     // 获取连续打卡天数
}
```

## 验收标准

- [ ] 设置页可开关喝水提醒功能
- [ ] 设置页可调节每日目标量 (滑块)
- [ ] 托盘菜单可快速记录喝水 (250/500/750ml)
- [ ] 托盘 tooltip 显示当日喝水进度
- [ ] Mini Break 休息页面底部显示喝水进度提示
- [ ] Long Break 休息页面显示水杯动画 + 快速记录按钮
- [ ] 仪表盘显示今日喝水量卡片
- [ ] 每日 0:00 自动重置当日计数
- [ ] 深色/浅色主题下显示正常
- [ ] 不产生额外的通知打扰 (默认仅在休息时提示)
