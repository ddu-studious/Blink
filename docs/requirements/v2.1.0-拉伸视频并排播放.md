# 拉伸视频并排播放 需求文档

**版本**: v2.1.0  
**创建日期**: 2026-02-25  
**状态**: 开发中

---

## 需求背景

当前长休息拉伸模式中，视频与步骤引导**互斥显示**：用户点击底部视频按钮后切换到全屏视频播放，步骤引导消失。用户无法在跟练视频的同时看到当前步骤进度和计时，体验割裂。

## 需求目标

将拉伸引导页面改为**左右分栏布局**：左侧显示教学视频（B 站/YouTube iframe），右侧显示步骤引导。用户在跟练视频的同时可以看到当前步骤、倒计时和完成进度。

---

## 功能需求

### P0 - 核心功能

| ID | 功能 | 说明 |
|----|------|------|
| F1 | 左右分栏布局 | 左侧视频（55%）+ 右侧步骤引导（45%） |
| F2 | 视频自动播放 | 动作加载时自动播放对应视频，默认静音 |
| F3 | 视频跟随切换 | 切换动作时，视频自动切换为新动作的教学视频 |
| F4 | 无视频降级 | 无网络或动作无视频时，回退为全宽步骤引导 |

### P1 - 重要功能

| ID | 功能 | 说明 |
|----|------|------|
| F5 | 视频平台切换 | 提供 B 站/YouTube 切换按钮 |
| F6 | 静音/开声切换 | 一键开关视频声音 |
| F7 | 视频加载状态 | 加载中显示骨架屏 |
| F8 | CSP 更新 | 支持 YouTube embed 域名 |

## 技术方案

### 布局结构

```
宽屏（>= 1024px）：
┌────────────────────┬──────────────────┐
│  视频区域 55%       │  步骤引导 45%     │
│  iframe 16:9       │  动作名/步骤/进度 │
└────────────────────┴──────────────────┘

窄屏 / 无视频：
┌────────────────────────────────────────┐
│  步骤引导 100%（当前布局）              │
└────────────────────────────────────────┘
```

### 关键实现

1. **CSP 更新**：`frame-src` 增加 `https://www.youtube.com`
2. **iframe 参数**：`autoplay=1&muted=1&danmaku=0&high_quality=1`
3. **视频切换**：更新 iframe `key` 属性强制重建，避免缓存
4. **降级策略**：`onError` 时隐藏视频区域
