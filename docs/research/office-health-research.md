# 办公健康功能扩展 技术调研

**版本**: v1.0
**创建日期**: 2026-02-18
**状态**: 已完成

## 调研背景

青眸（QingMou）当前定位为"护眼提醒"应用。但办公室工作者面临的健康问题远不止眼疲劳——久坐、脱水、颈椎病、腰椎间盘突出、腕管综合征、心理压力等都是高发问题。将产品理念从"护眼"扩展到"办公健康守护"，能覆盖更大的用户群和使用场景。

## 产品哲学升级

### 从"护眼"到"健康办公守护者"

```
当前: 青眸 = 护眼提醒工具
升级: 青眸 = 办公健康智能守护者

核心理念:
  科学 · 智能 · 美观 · 克制

三不原则:
  ✗ 不过度打扰 (每个提醒都有意义)
  ✗ 不贩卖焦虑 (正向引导而非恐吓)
  ✗ 不追踪成瘾 (帮助建立习惯后淡出)
```

### 产品定位对比

| 维度 | 当前 | 升级后 |
|------|------|--------|
| 定位 | 护眼提醒工具 | 办公健康智能守护者 |
| 功能 | 定时休息提醒 | 多维度健康关怀 |
| 用户 | 长时间用电脑的人 | 所有办公室/远程工作者 |
| 理念 | 保护眼睛 | 全方位健康办公 |
| 差异化 | 20-20-20法则 | 科学、美观、克制 |

## 设计原则

### 1. 克制 (Restraint)
> 每增加一个提醒，都要问: 这个打扰值得吗？
- 多功能共享同一个休息时段，不创造新的打断点
- 默认关闭高频提醒，让用户主动开启
- 提供"免打扰时段"和"智能感知"

### 2. 协同 (Synergy)
> 一次休息，多维关怀
- 护眼休息时顺便提醒喝水
- 长休息时提供拉伸引导
- 统计页面展示综合健康数据

### 3. 美观 (Aesthetic)
> 健康提醒也可以是一种享受
- 精美的动画和视觉效果
- 自然风光 + 健康引导融合
- 深色/浅色主题一致性

### 4. 科学 (Scientific)
> 每个功能都有研究支撑
- 20-20-20 法则 (护眼)
- 每 30 分钟站立一次 (WHO 建议)
- 每日 2000ml 饮水 (营养学)
- 正念冥想减压 (心理学)

## 商业化思考

| 模式 | 说明 |
|------|------|
| 免费 + 开源 | 基础功能免费，代码开源 (当前方案) |
| Freemium | 基础免费，高级功能付费 (统计分析/AI姿势/团队) |
| 一次性付费 | 像 TakeSip/DeskRest 一样一次性购买 |
| 订阅制 | 月/年订阅，持续内容更新 |

**推荐**: 保持开源免费的核心，可选的 Pro 功能（高级统计、AI 姿势、团队功能）采用一次性付费。
