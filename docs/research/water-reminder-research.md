**版本**: v1.0
**创建日期**: 2026-02-18
**状态**: 已完成

## 调研背景

办公室工作者长时间专注屏幕，容易忘记喝水。研究表明，轻度脱水（1-2% 体重损失）即会导致注意力下降 12%、头痛、疲劳。喝水提醒与护眼提醒（20-20-20 法则）天然协同——两者都是为办公健康服务，可共享提醒基础设施。

## 方案设计

### 核心理念

**"与护眼提醒协同，而非独立打扰"**

青眸已经有 Mini Break (每20分钟) 和 Long Break (每60分钟) 的提醒节奏。喝水提醒应该**搭便车**在这些休息节奏上，而不是创造新的打断。

### 三种集成方案

#### 方案 A: 休息页面内嵌喝水提示 (推荐)

在现有休息覆盖页面中加入喝水引导元素：
- Mini Break 时底部显示 "顺便喝口水 💧"
- Long Break 时显示更详细的水量进度
- 不额外弹窗，零额外打扰

**优点**: 零增量干扰、自然融合、实现简单
**缺点**: 仅在休息时可见

#### 方案 B: 托盘图标 + 进度指示

系统托盘增加水滴进度指示：
- 托盘 tooltip 显示 "已喝 3/8 杯"
- 定期（如每 2 小时）通过系统通知提醒
- 托盘菜单可快速记录喝水

**优点**: 始终可见、独立追踪
**缺点**: 额外通知可能扰人

#### 方案 C: 菜单栏水波动画 (TakeSip 风格)

独立的菜单栏水位指示器：
- 水位随喝水记录上升
- 水波纹动画
- 点击记录 + 查看历史

**优点**: 视觉美观、直观
**缺点**: 实现复杂度高

### 推荐方案

**方案 A + B 结合**: 主要在休息页面内嵌提示（零额外打扰），辅以托盘进度和可选的独立提醒。

## 技术实现

### 数据模型

```typescript
// 水量记录表 (SQLite)
interface WaterRecord {
  id: number
  timestamp: string    // ISO 时间
  amount: number       // ml
  type: 'manual' | 'quick'  // 手动输入 / 快速记录
}

// 每日水量统计
interface DailyWaterStats {
  date: string         // YYYY-MM-DD
  totalAmount: number  // ml
  goalAmount: number   // ml
  recordCount: number  // 记录次数
  goalReached: boolean
}

// 水量设置
interface WaterSettings {
  enabled: boolean
  dailyGoal: number          // ml (默认 2000)
  quickAmounts: number[]     // 快速记录选项 [250, 500, 750]
  reminderEnabled: boolean   // 独立提醒
  reminderInterval: number   // 分钟 (60-180)
  showInBreak: boolean       // 休息页面显示
}
```
