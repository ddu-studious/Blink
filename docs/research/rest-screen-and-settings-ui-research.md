# 休息屏幕内容方案 & 设置页面 UI 调研

**版本**: v1.0
**创建日期**: 2026-02-15
**状态**: 已完成

## 调研背景

青眸当前的休息屏幕仅有一种默认模式（倒计时进度环 + 护眼知识文字 + B站视频入口），用户希望有更多对眼睛好的休息方式可选。同时设置页面需要参考 Apple 等流行设计进行重新设计。

## 一、休息屏幕内容方案

### 方案 1: 经典模式（当前默认，保留）

- 倒计时进度环 + 护眼知识文字 + B站视频入口
- 短休息：眼部小知识 + 眼保健操视频
- 长休息：身体活动建议 + 运动视频列表
- **适合人群**：想快速完成休息、不需要太多仪式感的用户

### 方案 2: 自然风光轮播模式

- 全屏高清自然图片轮播（森林/海洋/山川/草原/日出日落）
- **以绿色系为主**（绿色波长适中，对眼睛最友好）
- 图片切换用淡入淡出动画（Framer Motion crossfade）
- 底部半透明毛玻璃层显示倒计时
- 可选配合环境音效：鸟鸣、溪流、风声、雨声
- **参考**: CareUEyes 壁纸+背景音乐、macOS 屏保
- **科学依据**: Stretchly Break Idea "Nature is linked to positive emotions and decreased stress"

### 方案 3: 引导呼吸/冥想模式

- 动态呼吸引导动画（圆形扩大=吸气4秒，保持4秒，缩小=呼气6秒）
- 极简深色背景 + 柔和渐变色光晕
- 文字引导："吸气..." → "屏住..." → "呼气..."
- 可选配合白噪音/自然音/引导语音
- **参考**: Stretchly "Meditation"、"Slow Breathing"、"Imaginative visualization"
- **科学依据**: PubMed 研究表明控制慢呼吸能优化生理参数，正念冥想被证实能减少焦虑和压力

### 方案 4: 互动眼部训练模式

| 训练项目 | 实现方式 | 科学依据 |
|---------|---------|---------|
| **8字追踪** | 屏幕上缓慢移动光点描绘8字轨迹 | 眼瑜伽标准练习 |
| **时钟运动** | 光点按12/3/6/9点钟方向移动 | 眼科推荐眼球运动 |
| **焦点切换** | 提示"看近处→看远处"交替 | 20-20-20 法则延伸 |
| **掌敷法** | 图文引导：搓热双手→闭眼轻敷→深呼吸 | Mayo Clinic 推荐 |
| **有意识眨眼** | 节拍式提示每4-5秒眨一次 | 屏幕使用减少眨眼频率 |
| **远眺引导** | 绿色远景图+"看向窗外最远处" | 20-20-20 法则核心 |

- **参考**: Stretchly "Focus change"、"Palming"、"Blink" Ideas
- **科学依据**: 研究发现每周两次眼瑜伽训练持续8周可显著降低眼疲劳

### 方案 5: 拉伸运动引导模式（Long Break 专用）

- 简洁人体轮廓动画，高亮当前运动部位
- 分步骤自动切换（每步10-15秒）：颈部→肩部→手腕→扩胸→腰部
- 文字说明 + 计数提示 + 呼吸节拍
- **参考**: Stretchly 20+ 条拉伸动作提示
- **适合**: Long Break 5分钟完整拉伸序列

### 方案 6: 纯黑/暗屏模式

- 完全黑屏或极暗画面（亮度 < 5%）
- 仅保留极微弱倒计时文字
- 可选配合轻柔白噪音
- **适合**: 眼睛特别疲劳、深夜使用、偏头痛用户
- **科学依据**: 减少蓝光和亮度对视网膜的直接刺激

### 推荐优先级

| 优先级 | 方案 | 实现难度 | 推荐理由 |
|--------|------|---------|---------|
| P0 | 方案1 经典模式 | 已实现 | 保留当前 |
| P0 | 方案2 自然风光 | 中等 | 用户明确需求，视觉吸引力强 |
| P0 | 方案6 纯黑模式 | 极低 | 实现简单，科学有效 |
| P1 | 方案3 呼吸引导 | 中等 | 科学依据强，用户价值高 |
| P1 | 方案4 眼部训练 | 中高 | 差异化功能，专业度高 |
| P2 | 方案5 拉伸引导 | 高 | 需要动画素材，Long Break 专属 |

## 二、设置页面 UI 设计方案

### 当前问题

- 侧边栏较窄（140px），没有图标
- 控件用的是原生 HTML（range slider 不够精致）
- 缺少搜索功能、动画过渡
- 标题栏显示较朴素

### 风格 A: Apple 系统设置风格（推荐）

- 侧边栏 200-220px，带搜索框
- 每个导航项配彩色圆角方形图标（仿 SF Symbols）
- 内容区分组使用圆角卡片
- Toggle Switch 使用 Apple 风格（更大、更圆润）
- 选择器使用 Segmented Control
- 过渡动画：切换Tab时内容区域淡入

### 风格 B: 极简扁平风格（Linear/Notion）

- 无侧边栏，顶部 Segmented Control
- 极简无边框设计，用分隔线区分组
- 黑白灰主色调

### 风格 C: Material Design 列表风格

- 单栏滚动列表，分组标题
- 每行：左图标+标题描述+右控件

### 风格 D: 模块化卡片网格风格

- 网格布局，2-3列卡片
- 每个功能模块一张卡片

### 设计推荐

| 优先级 | 风格 | 推荐指数 | 理由 |
|--------|------|---------|------|
| **推荐** | 风格A (Apple) | 5/5 | 与系统一致、专业、可扩展 |
| 备选 | 风格B (极简) | 4/5 | 设置项少时效果好 |
| 备选 | 风格C (Material) | 3/5 | 更适合移动端 |
| 备选 | 风格D (卡片) | 3/5 | 创新但不太适合密集设置 |
