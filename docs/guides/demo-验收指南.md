# 青眸 (QingMou) Demo 验收指南

**版本**: v1.0.0  
**创建日期**: 2026-02-15  
**状态**: 开发中

---

## 启动应用

```bash
# 安装依赖 (首次)
npm install

# 启动开发模式
npm run dev
```

启动后，你会看到：
- macOS 菜单栏 (顶部右侧) 出现一个 **眼睛图标** + **倒计时数字**
- 首次运行会自动弹出设置窗口
- 计时器自动开始运行

> 提示：开发模式下按 **F12** 可以打开 DevTools 调试

---

## 验收清单

### 1. 系统托盘 (菜单栏)

**验收步骤：**

- [ ] **看到托盘图标** — 菜单栏右侧应有一个眼睛形状的图标
- [ ] **看到倒计时** — 图标旁边应显示倒计时数字 (如 `19:30`)，表示距离下次短休息的时间
- [ ] **鼠标悬停提示** — 将鼠标悬停在图标上，tooltip 会显示 `青眸 - 距下次休息 xx:xx`
- [ ] **右键菜单** — 右键点击图标，弹出菜单：
  - `青眸 护眼提醒` (标题，不可点击)
  - `暂停护眼` / `恢复护眼` / `开始护眼` (根据当前状态切换)
  - `立即休息` — 触发一次短休息
  - `统计` — 打开统计窗口
  - `设置` — 打开设置窗口
  - `退出青眸` — 退出应用

**快速验证：**
1. 观察倒计时是否每秒递减
2. 点击 `暂停护眼` → 菜单栏显示 `⏸`
3. 点击 `恢复护眼` → 倒计时继续
4. 点击 `立即休息` → 全屏覆盖出现

---

### 2. 短休息 (Mini Break)

**默认设置：** 每 20 分钟提醒一次，休息 20 秒

**验收步骤（快速测试建议先在设置里把间隔调为 1 分钟）：**

- [ ] **30 秒预警通知** — 休息前 30 秒会弹出系统通知 `青眸 - 短休息即将开始`
- [ ] **全屏覆盖出现** — 半透明黑色遮罩覆盖全屏
- [ ] **倒计时环** — 页面中央有一个蓝色进度环 + 数字倒计时 (`:20` → `:00`)
- [ ] **提示文字** — 显示 `望向远方，让眼睛放松一下` + 随机护眼小知识
- [ ] **眼部运动视频** — 底部有 `👁️ 眼保健操` 和 `👁️ 眼肌训练操` 按钮
- [ ] **跳过按钮** — 延迟 5 秒后出现 `跳过` 按钮
- [ ] **自动关闭** — 倒计时结束后覆盖窗口自动消失
- [ ] **声音提示** — 休息开始和结束时有提示音
- [ ] **菜单栏显示** — 休息期间菜单栏显示 `休 :15` 格式的倒计时

**多屏验证 (如果有外接显示器)：**
- [ ] 所有屏幕都被覆盖
- [ ] 只有主屏幕显示交互内容 (倒计时、按钮)
- [ ] 副屏仅显示 `🌿 休息一下`

---

### 3. 长休息 (Long Break)

**默认设置：** 每 60 分钟提醒一次，休息 5 分钟

**验收步骤（可通过托盘菜单的 `立即休息` 触发）：**

> 注意：当前 `立即休息` 触发的是短休息 (mini)。如需测试长休息，建议在设置中把长休息间隔调小。

- [ ] **全屏覆盖** — 与短休息类似，但进度环颜色为 **绿色**
- [ ] **标题显示** — 显示 `长休息` (不是 `短休息`)
- [ ] **提示文字** — 显示 `站起来活动一下身体吧` + 运动建议
- [ ] **运动视频推荐** — 显示完整的 5 个视频按钮：
  - 👁️ 眼保健操
  - 👁️ 眼肌训练操
  - 💪 久坐拉伸
  - 💪 天鹅颈直角肩
  - 💪 每日拉伸
- [ ] **点击视频按钮** — 切换到 B 站视频嵌入播放模式
- [ ] **视频播放界面** — 显示视频标题、`返回` 按钮、底部倒计时

### 4. 全局快捷键

| 快捷键 | 功能 | 验收方式 |
|--------|------|----------|
| `Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Win) | 切换暂停/恢复 | 按下后菜单栏倒计时暂停/恢复 |
| `Cmd+Shift+B` (Mac) / `Ctrl+Shift+B` (Win) | 立即休息 | 按下后全屏覆盖立即出现 |
| `Cmd+Shift+S` (Mac) / `Ctrl+Shift+S` (Win) | 跳过休息 | 在休息中按下，覆盖窗口关闭 |

- [ ] 在任何应用中按快捷键都能生效 (全局)
- [ ] `Cmd+Shift+P` 在空闲状态下会启动计时

> 注意：`Cmd+Shift+P` 可能与 VS Code 的命令面板冲突。如果不生效，先关闭 Cursor/VS Code 再测试。

### 5. 设置窗口

**打开方式：** 托盘右键 → `设置`

**Tab 1 — 提醒设置：**
- [ ] **短休息开关** — 可以关闭/开启短休息
- [ ] **短休息间隔** — 滑块调节 10-60 分钟
- [ ] **短休息时长** — 滑块调节 10-60 秒
- [ ] **长休息开关** — 可以关闭/开启长休息
- [ ] **长休息间隔** — 滑块调节 30-180 分钟
- [ ] **长休息时长** — 滑块调节 60-900 秒
- [ ] **声音提醒开关** — 开启/关闭提示音

**Tab 2 — 智能设置：**
- [ ] **空闲检测** — 开关 + 空闲阈值 (分钟)
- [ ] **免打扰感知** — 开启后，免打扰模式下暂停提醒
- [ ] **全屏应用检测** — 全屏时暂停提醒
- [ ] **严格模式** — 开启后隐藏跳过按钮

**Tab 3 — 通用设置：**
- [ ] **开机自启动** — 开关
- [ ] **主题** — 亮色/暗色/跟随系统
- [ ] **语言** — 中文/英文

**验证设置保存：**
1. 修改某个设置（如短休息间隔改为 1 分钟）
2. 关闭设置窗口
3. 重新打开设置窗口 → 确认设置值已保存

### 6. 统计窗口

**打开方式：** 托盘右键 → `统计`

- [ ] **今日统计卡片** — 显示已完成的短/长休息次数
- [ ] **达成率** — 显示今日休息目标完成百分比
- [ ] **计时器状态** — 显示当前计时器运行状态

### 7. 智能场景感知

**空闲检测：**
- [ ] 离开电脑超过 5 分钟 (默认) → 计时自动暂停
- [ ] 回来后 → 计时自动恢复
- 验证方式：等待 5 分钟不碰电脑，或在设置中调低空闲阈值

**休眠/锁屏感知：**
- [ ] 合上笔记本 → 计时暂停
- [ ] 打开笔记本 → 计时恢复
- [ ] 锁屏 → 计时暂停
- [ ] 解锁 → 计时恢复

**免打扰模式 (macOS)：**
- [ ] 开启系统 "专注模式"/"免打扰" → 提醒暂停
- [ ] 关闭专注模式 → 提醒恢复

## 已知限制

| 项目 | 说明 |
|------|------|
| 托盘 `立即休息` | 目前触发的是短休息 (mini)，不支持选择长休息 |
| 菜单栏倒计时 | macOS 专属功能，Windows/Linux 不显示 |
| B 站视频 | 需要网络连接，可能受 CSP 和网络环境影响 |
| 声音提示 | 使用 Web Audio 合成音效，非真实音频文件 |
| 全屏应用检测 | 配置项存在，但检测逻辑未完整实现 |
| 音量/跳过延迟 | 后端支持，设置 UI 未暴露 |
| 通知模式选择 | 后端支持 overlay/notification/both，UI 未暴露 |

## 常见问题

**Q: 看不到菜单栏图标？**  
A: macOS 可能需要在菜单栏拖动来显示被隐藏的图标。也可以检查控制台有无错误日志。

**Q: 快捷键不生效？**  
A: 可能与其他应用的快捷键冲突 (如 VS Code 的 `Cmd+Shift+P`)。关闭冲突应用后重试。

**Q: 全屏覆盖无法盖住其他全屏应用？**  
A: 这是 macOS 的全屏应用空间机制限制，覆盖窗口使用 `screen-saver` 级别的 alwaysOnTop。

**Q: 设置修改后不生效？**  
A: 设置修改实时生效，无需重启。如果不生效请检查控制台日志。
