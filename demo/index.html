Demo 6: 后台架构能力

主进程核心模块的功能验证（非 UI，通过日志验证）

⏰ TimerManager

  • 20-20-20 法则定时触发
  • 长休息独立计时
  • 暂停/恢复/跳过/手动触发
  • 休息完成自动记录到 SQLite

🔋 PowerMonitor

  • 系统休眠 → 自动暂停计时
  • 系统唤醒 → 自动恢复计时
  • 锁屏 → 暂停 / 解锁 → 恢复

💤 IdleDetector

  • 每30秒检测系统空闲时间
  • 空闲超阈值 → 自动暂停
  • 用户活动恢复 → 自动继续

💾 数据持久化

  • 设置 → electron-store (JSON)
  • 统计 → SQLite (better-sqlite3)
  • 路径: ~/Library/Application Support/qingmou/
